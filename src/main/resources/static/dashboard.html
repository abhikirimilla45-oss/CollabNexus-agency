    Account security

    How this session is protected.

    Session controls

    End this browser session immediately.

    Signing out invalidates the server-side session and clears the security context. No password or role value is ever stored in browser storage.

    Active protections

    Implemented in this build.

    • BCrypt password hashing with a per-password salt
    • HTTP-only session cookie with SameSite=Lax
    • CSRF token required for state-changing requests
    • Role checks enforced on the server for every protected endpoint
    • Account status re-checked on every authenticated request
    • Rate limiting on sign-in and registration attempts
    • Consistent JSON errors without internal exception details

    This records a status change. It does not transfer money.
