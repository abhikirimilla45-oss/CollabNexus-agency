What is CollabNexus?

CollabNexus is a two-sided influencer marketing platform for brands, agencies, and creators. It covers creator discovery, campaign publishing, applications, collaborations, contracts, deliverables, payment records, messaging, reviews, and moderation.

Is the marketplace live?

Yes, the application is runnable and the workflows are implemented. The included creators, campaigns, metrics, and testimonials are clearly labelled demonstration data, not real marketplace records.

How are creators and brands matched?

Brands publish structured briefs with niche, platform, budget, and timing. Creators search and filter those briefs, then apply with a proposal, price, and availability. There is no hidden ranking or invented performance score.

Can a creator apply to the same campaign twice?

No. A unique database constraint and a service-level check prevent duplicate applications for the same creator and campaign. A withdrawn application can be reviewed under the documented application rules.

What happens when a brand accepts an application?

An accepted application creates a collaboration record with the agreed amount and currency. The collaboration then moves through explicit states to contract acknowledgement, delivery, completion, or cancellation. Invalid transitions are rejected by the API.

Can a campaign accept more creators than its capacity?

No. Acceptance checks the campaign capacity inside a transaction and the database enforces unique applications. A concurrency test exercises the capacity rule so simultaneous accepts cannot exceed the limit.

Does CollabNexus process payments?

No. The first version records payment milestones and status changes manually. It never stores card numbers or claims that money moved when only a database record changed. A verified payment provider can be integrated later.

Are the follower and engagement figures real?

No. Every figure shown on the public site is illustrative sample data for design review. Real profile metrics would only be entered or imported with authorised access.

How is account data protected?

Passwords are hashed with BCrypt. Authentication uses server-side sessions with HTTP-only, SameSite cookies and CSRF tokens. Role checks and ownership validation happen on the server, and suspended accounts are rejected on every authenticated request.

Can I upload files?

Creators can attach a supporting file to a deliverable submission. Uploads are size-limited, type-checked, stored outside the web root, and served only to authorised collaboration participants. Executable content is never served as a web page.

How do reviews and reports work?

Only participants in an eligible completed collaboration can review each other, and duplicate reviews are blocked. Users can report profiles, campaigns, messages, reviews, or other issues. Administrators review reports, record actions, and keep a moderation history.

Can agencies manage multiple brands?

An agency role is planned as an optional extension. The current build supports one brand profile per brand account and keeps the user and profile records separate so an agency module can be added without duplicating data.
