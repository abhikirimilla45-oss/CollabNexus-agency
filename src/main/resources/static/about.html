About CollabNexus

A portfolio project built like a product, not a demo.

CollabNexus is a two-sided influencer marketing platform delivered as ten runnable, tested phases. The final build covers discovery, applications, collaborations, contracts, deliverables, payment records, analytics, messaging, reviews, moderation, and production deployment guidance.

Why it exists

Influencer work deserves a better record than an inbox.

Most creator collaborations still live across email threads, spreadsheets, and screenshots. CollabNexus explores what happens when discovery, agreements, delivery, payment status, and moderation share one validated workflow.

The goal

A realistic path from portfolio to product.

The architecture is a modular monolith: one Spring Boot application serving a JSON API and a static frontend. It is intentionally simple enough for a learner to reason about and structured enough to grow.

  • Clear package boundaries for each business capability.
  • DTOs at the API edge so entities never leave the server.
  • Flyway migrations for both H2 and MySQL profiles.
  • Automated tests around the rules that carry risk.
The standards

Honesty is part of the interface.

Sample creators, campaigns, and testimonials are always labelled. The platform does not invent reach, engagement, conversions, or payments, and it does not claim that a database record is a money transfer.

  • Demonstration data is marked wherever it appears.
  • Verification is shown separately from platform endorsement.
  • Payment status is a record, never proof of settlement.
  • Limitations are documented instead of hidden.

Design principles

Decisions that shape the build.

These principles make the project easier to review, extend, and explain to a non-technical stakeholder.

Delivery

The stack

Boring technology, used deliberately.

  1. 01

    Java 21 + Spring Boot

    Spring Web, Spring Data JPA, Spring Security, Bean Validation, and Actuator with a Maven Wrapper for reproducible builds.

  2. 02

    H2 and MySQL

    File-based H2 for local development, a MySQL profile for later deployment, and Flyway migrations for both vendors.

  3. 03

    HTML, CSS, vanilla JS

    No frontend build system. The browser talks to the same REST API a future mobile client could use.

  4. 04

    Tests that matter

    JUnit 5, Spring Boot Test, and MockMvc cover ownership, lifecycle rules, validation, and the end-to-end collaboration path.

Is this a real commercial service?

Not yet. CollabNexus is a portfolio project with a realistic path toward a commercial SaaS product. Demonstration accounts, campaigns, and metrics are clearly labelled.

Is the data persistent?

Yes. Local development uses a file-based H2 database under ./data, so records survive restarts. Tests use an in-memory database and never modify local data.

Can I deploy it?

The project includes a production profile, Flyway migrations, a Dockerfile, and Docker Compose configuration. A real deployment still needs HTTPS, secret management, backups, and a monitored database.
